# Python Factorial Recursive Iterative

This example demonstrates recursion in Python by calculating the factorial of a number using a recursive function. It also includes an iterative implementation for comparison, highlighting the two common approaches to solving problems. The recursive function clearly shows the base case and the recursive step.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
